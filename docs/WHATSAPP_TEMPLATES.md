# PLYDECK WhatsApp template bodies

Use language `en_US` (or the matching table language) and Utility category. The numbered placeholders are positional.

## plydeck_booking_received

PLYDECK reservation {{1}} confirmed for pool {{2}}. Final order value: INR {{3}}. Your selected slots are locked.

## plydeck_pool_confirmed

Pool {{1}} is confirmed for order {{2}} in {{3}}. Target hub delivery: {{4}}.

## plydeck_qc_due

Order {{1}} has completed QC for pool {{2}}. We will share dispatch details next.

## plydeck_dispatched

Order {{1}} for {{2}} has been dispatched. Contact PLYDECK for handoff details.

## plydeck_pool_cancelled

Pool {{1}} was cancelled because {{3}}. Reservation {{2}} has been released.

## plydeck_waitlist_offer

A slot is available in pool {{1}}: slot {{2}}. Offer expires {{3}}. Log in to PLYDECK to review and reserve.

The former payment, default and refund templates are intentionally disabled by migration 008.
